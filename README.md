# 去过的地方

我去过的景点，五档分级：**夯 → 顶级 → 人上人 → npc → 拉完了**。

👉 https://froxieye.github.io/scenic-tiers/

![预览](shot-dense.png)

> 上图是 60 条示例数据。仓库里只带一条真实记录（黄岩石窟 / 中国）。

每条记录两个字段：**名称**和**国家**。

## 设计

参考了被夸过设计的同类列表产品——Letterboxd 靠海报、Beli 靠照片和评分徽章、
Nomad List 靠城市图配国旗——它们的**视觉重量全部来自图像**。这份数据里唯一能
长出图像的字段是国家，所以国旗就是主材。

- **国旗是唯一的颜色来源。** 每条记录按国家名查 ISO 码（内置 116 个中文国名映射），
  渲染成 28px 圆形国旗；认不出的国家退回同尺寸的首字占位圆，布局不塌。
  图标来自 [circle-flags](https://github.com/HatScripts/circle-flags)，走 jsDelivr，单个 300–900 字节。
- **顶部国旗墙同时就是筛选器。** 点一面国旗按国家筛选，未选中的变暗到 34%，再点一次取消。
- **排名不靠颜色。** 位置已经说明了档位，再给每档配色是冗余编码。改用档位徽章的
  填充深浅表达，五枚徽章一律中性、零色相，且每一枚的文字对比都 ≥4.5:1
  （过了中点就把字色翻过来，否则中间档会掉到 3:1 以下）。
- 浅色与深色两套配色，跟随系统，对比度分别验过。
- 系统字体直出，不加载网络字体。

## 用法

| 做什么 | 在哪 |
| --- | --- |
| 添加 | 右上角「添加」 |
| 看详情 / 改 / 删 | 点条目本身，在弹窗里操作 |
| 按国家筛选 | 点顶部的国旗，再点一次取消 |
| 搜索 | 搜索框，名称和国家都能搜 |
| 备份 / 恢复 | 页脚的导出、导入 |

填国家时输入框带候选列表，认得出的国家会在弹窗标题旁实时显示国旗。

## 数据存在哪

浏览器的 localStorage，**按设备存，不上传服务器**。手机上加的，电脑上看不到。
换设备或清缓存前记得导出 JSON。

存档是一个数组，每项四个键：`id` `name` `country` `tier`。
`tier` 取 `hang` / `top` / `ren` / `npc` / `la`。

旧版有过 `place`/`where`（地点）、`date`/`when`（时间）、`note`/`said`（一句话），
现已全部取消，读进来即丢弃。旧记录没有国家字段，凡是有过地点的一律按「中国」处理。

## 本地跑

整站就是一个 `index.html`，没有依赖、不用构建（国旗走 CDN，离线时自动退回占位圆）。

```bash
python3 -m http.server 8000
# http://127.0.0.1:8000/
```

## 加国家

`index.html` 里的 `ISO` 对象是国家名到两位国家码的映射，照着加一行即可。
