# 去过的地方

我去过的景点，五档分级：**夯 → 顶级 → 人上人 → npc → 拉完了**。

👉 https://froxieye.github.io/scenic-tiers/

![预览](shot-dense.png)

> 上图是 60 条示例数据。仓库里只带一条真实记录（黄岩石窟 / 中国）。

每条记录只有两个字段：**名称**和**国家**。

## 设计

- **排名不靠颜色。** 既然已经按档位分组，位置就说明了排名，再给每档配一种颜色是冗余编码。
  改成用字号和墨色表达：夯最大最黑（54px / 19.8:1），往下逐级变小变淡，到拉完了是 27px / 3.25:1。
  整页随滚动"泄气"。五个档位标题一律中性灰，色相为零。
- **全站只有一个强调色**（`#1D2FD8`，深色模式 `#8A96FF`），只用在计数、选中的筛选条、主按钮和焦点环上。其余全是中性色。
- **国家是一等字段**，顶部自动生成筛选条，按数量降序、并列按拼音排序。
- 两个字段撑不满一整行，所以条目走**双栏流式**；窄屏自动回到单栏。
- 深色模式跟随系统，两套配色的对比度都单独验过。
- 不用网络字体，系统字体直出。

## 用法

| 做什么 | 在哪 |

| 添加 | 右上角「添加」 |

## 数据存在哪

浏览器的 localStorage，**按设备存，不上传服务器**。手机上加的，电脑上看不到。
换设备或清缓存前记得导出 JSON。

存档是一个数组，每项四个键：`id` `name` `country` `tier`。
`tier` 取 `hang` / `top` / `ren` / `npc` / `la`。

旧版有过 `place`/`where`（地点）、`date`/`when`（时间）、`note`/`said`（一句话），现已全部取消，
读进来即丢弃。旧记录没有国家字段，凡是有过地点的一律按「中国」处理，不对的点开改一下即可。

## 本地跑

整站就是一个 `index.html`，没有依赖、不用构建。双击即可打开；
如果浏览器禁用了本地文件的 localStorage（Safari 常见），用本地服务打开：

```bash
python3 -m http.server 8000
# http://127.0.0.1:8000/
```

## 改档位

档位的名字、注解、字号层级都在 `index.html` 里的 `TIERS` 数组和 `.t1`–`.t5` 这几条 CSS。
