# 景点分级 · 从夯到拉完了

我去过的景点，五档分级：**夯 → 顶级 → 人上人 → npc → 拉完了**。

👉 在线访问：https://froxieye.github.io/scenic-tiers/

![预览](shot-final.png)

## 用法

- **添加景点** —— 右上角「+ 添加景点」，填名称、地点、时间、评级、一句话评价
- **改 / 删** —— 鼠标悬停到卡片上，右上角出现按钮
- **搜索** —— 顶部搜索框按名称、地点、评价过滤
- **备份** —— 底部「导出 JSON」/「导入 JSON」

## 数据存在哪

浏览器的 localStorage，**按设备存，不上传服务器**。换设备或清缓存前记得导出 JSON。

## 本地跑

整站就是一个 `index.html`，没有依赖、不用构建。双击即可打开；
如果浏览器禁用了本地文件的 localStorage（Safari 常见），用本地服务打开：

```bash
python3 -m http.server 8000
# 然后访问 http://127.0.0.1:8000/
```

## 改档位

档位文案写在 `index.html` 顶部的 `TIERS` 数组里，改名字和注解直接改那几行即可。
