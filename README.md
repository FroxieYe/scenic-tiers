# 去过的地方

我去过的景点，六档分级：**神级 → 夯 → 顶级 → 人上人 → npc → 拉完了**。

👉 https://froxieye.github.io/scenic-tiers/

![预览](shot-dense.png)

> 上图是 60 条示例数据。仓库里只带一条真实记录（黄岩石窟 / 中国）。

每条记录两个字段：**名称**和**国家**。

## 版式

照着 Figma Community 的
[Tier List Template](https://www.figma.com/community/file/1038236539163845796/tier-list-template)
做，色值是从模板封面图里逐点采样出来的：

| 位置 | 取值 |
| --- | --- |
| 神级 / 夯 / 顶级 / 人上人 / npc / 拉完了 | `#FF7F7F` `#FFBF7F` `#FFFF7F` `#7FFF7F` `#7FFFFF` `#7F7FFF` |
| 条目区底色 | `#1A1A1A` |
| 行缝 | `#000000` |
| 主按钮（封面右下那枚白胶囊） | `#FFFFFF` 底配黑色粗字 |

左侧彩色标签块一律黑字，六档对比度 6.4:1 起。条目是 92×92 的方块，照模板的样子左对齐铺排。

## 国旗

条目方块里的图是国旗。国家名查 ISO 码（内置 116 个中文国名映射），
取 [circle-flags](https://github.com/HatScripts/circle-flags) 的圆形 SVG，走 jsDelivr，单个 300–900 字节。
认不出的国家退回同尺寸的首字占位圆，图加载失败也有 `onerror` 兜底，布局不塌。

**顶部那排国旗同时就是筛选器**：点一面按国家筛选，未选中的变暗到 30%，再点一次取消。

## 用法

| 做什么 | 在哪 |
| --- | --- |
| 添加 | 右上角「添加」 |
| 看详情 / 改 / 删 | 点方块本身，在弹窗里操作 |
| 按国家筛选 | 点顶部的国旗，再点一次取消 |
| 搜索 | 搜索框，名称和国家都能搜 |
| 备份 / 恢复 | 页脚的导出、导入 |

填国家时输入框带候选列表，认得出的国家会在弹窗标题旁实时显示国旗。

## 数据存在哪

浏览器的 localStorage，**按设备存，不上传服务器**。手机上加的，电脑上看不到。
换设备或清缓存前记得导出 JSON。

存档是一个数组，每项四个键：`id` `name` `country` `tier`。
`tier` 取 `shen` / `hang` / `top` / `ren` / `npc` / `la`。

旧版有过 `place`/`where`（地点）、`date`/`when`（时间）、`note`/`said`（一句话），
现已全部取消，读进来即丢弃。旧记录没有国家字段，凡是有过地点的一律按「中国」处理。

## 本地跑

整站就是一个 `index.html`，没有依赖、不用构建（国旗走 CDN，离线时自动退回占位圆）。

```bash
python3 -m http.server 8000
# http://127.0.0.1:8000/
```

## 加国家 / 改档位

`index.html` 里的 `ISO` 对象是国家名到两位国家码的映射，照着加一行即可。
档位的名字、注解、颜色在 `TIERS` 数组和 `--t1`–`--t5` 这几个变量。
